# 分镜狮 (Storyboard Lion) - 项目概览

## 项目简介

**分镜狮**是一个基于 Flask 的 Web 应用，专为 AI 图像生成和分镜管理设计。它支持多影片（项目）管理、多种 AI 生图模型插件、图片编辑（裁剪/换脸/图生图）以及故事板创作功能。

## 核心功能

### 1. 快速生图
- 支持上传最多 10 张参考图
- 三种提示词模式：Raw 模式、分镜模式、角色模式
- 支持多种分辨率和宽高比
- 插件级联调用（fallback 机制）

### 2. 图片编辑
- **裁剪模式**：四格裁剪、自由裁剪
- **区域编辑**：选取图片区域进行换脸或图生图

### 3. 故事板
- 创建和管理分镜故事板
- 每个分镜包含：画面、机位运动、景别、镜头时长、音频/音效、备注
- 支持分镜拖动排序
- 最多支持 12 个分镜

### 4. 影片管理
- 多影片（项目）数据隔离
- 每个影片有独立的历史记录、故事板、快捷访问数据
- 支持数据迁移（从旧版单影片结构）

### 5. 历史记录
- 分页展示生成历史
- 支持批量选择和删除
- 可查看生成参数详情

### 6. 快捷访问
- 收藏常用图片
- 按影片隔离
- 支持分类和备注

### 7. 插件系统
- 支持多种生图 API
- 插件级别配置（启用/禁用、排序）
- 自动 fallback 机制

## 技术栈

### 后端
- **框架**: Flask (Python)
- **图片处理**: Pillow (PIL)
- **HTTP 请求**: requests
- **环境配置**: python-dotenv

### 前端
- **UI 框架**: Bootstrap 5 (深色主题)
- **DOM 操作**: jQuery 3.7
- **图片查看**: Lightbox2
- **拖拽排序**: 原生 HTML5 Drag API

### 外部服务
- **图片托管**: ImgBB / GitHub + jsDelivr / 火山 TOS
- **生图 API**: NanoBanana / Seedream (火山引擎) / 其他插件

## 快速启动

1. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

2. **配置环境变量**
   ```bash
   cp .env.example .env
   # 编辑 .env 填入必要的 API Key
   ```

3. **启动应用**
   ```bash
   python main.py
   ```

4. **访问应用**
   打开浏览器访问 `http://localhost:5000`

## 环境变量配置

### 必需配置
- `SESSION_KEY` - Flask session 密钥
- `IMGBB_API_KEY` 或 GitHub 配置 - 图片上传服务

### 插件配置（各插件目录下的 .env）
- `GRSAI_API_KEY` - NanoBanana API Key
- `ARK_API_KEY` - 火山引擎 API Key

### 可选配置
- `UPLOAD_BACKEND` - 上传后端 (imgbb/github_jsdelivr)
- `GITHUB_USERNAME/REPO/BRANCH` - GitHub 配置
- `PLUGIN_ENABLED` - 启用的插件列表
- `FACE_SWAP_PLUGIN` - 换脸插件名称
